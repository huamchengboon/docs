*[AD CS]: Active Directory Certificate Services
*[AD DS]: Active Directory Domain Services
*[BITS]: Background Intelligent Transfer Service, the Windows download engine WSUS uses
*[CA]: Certificate Authority
*[CBS]: Component-Based Servicing, the Windows component that installs updates
*[CU]: Cumulative update: one monthly package that contains every earlier fix
*[DC]: Domain controller
*[EFI]: The EFI system partition, a small disk partition that holds the boot files
*[FQDN]: Fully qualified domain name, for example adfs.example.local
*[GPO]: Group Policy Object
*[IdP]: Identity provider: the system that signs the user in and issues tokens
*[IIS]: Internet Information Services, the Windows web server
*[KDS]: Key Distribution Service; its root key is needed before creating a gMSA
*[NAT]: Network address translation
*[OIDC]: OpenID Connect, a sign-in protocol built on OAuth 2.0
*[RC4]: An old Kerberos encryption type, disabled by default on Windows Server 2025
*[SAML]: Security Assertion Markup Language, an older sign-in protocol
*[SAN]: Subject Alternative Name: the extra host names a TLS certificate is valid for
*[SPN]: Service Principal Name: tells Kerberos which account runs a service
*[SUSDB]: The WSUS database
*[TLS]: Transport Layer Security, the encryption behind HTTPS
*[UAC]: User Account Control
*[UPN]: User principal name, for example user@example.local
*[WIA]: Windows Integrated Authentication: silent sign-in with the user's Windows logon
*[WID]: Windows Internal Database, the built-in SQL engine that holds SUSDB
*[WSL]: Windows Subsystem for Linux
*[gMSA]: Group Managed Service Account: a service account whose password Windows rotates
